# Informe Final - Ciencia de Datos

Este repositorio contiene el desarrollo y análisis realizado para la **Entrega Final de la materia Ciencia de Datos**.

El trabajo se basa en el estudio de un conjunto de datos de exoplanetas descubiertos entre los años 1992 y 2026, aplicando técnicas de análisis exploratorio para obtener información relevante, detectar patrones y elaborar conclusiones fundamentadas.

## Objetivo

Realizar un análisis exploratorio de un dataset de exoplanetas con el fin de comprender sus características principales, identificar relaciones entre variables y obtener conclusiones relevantes a partir de los datos disponibles.

---

## Contenido del Informe

### ✔️ Análisis Descriptivo

Se realizó una exploración general del dataset incluyendo:

* Cantidad de registros y variables.
* Período de descubrimiento de exoplanetas.
* Identificación de valores faltantes.
* Distribución de métodos de descubrimiento.
* Distribución de tipos de estrellas anfitrionas.
* Análisis de exoplanetas ubicados en zona habitable.

### ✔️ Detección de Patrones

Se identificaron tendencias y relaciones relevantes dentro de los datos:

* Predominio del método Transit en los descubrimientos.
* Relación entre período orbital y distancia al astro anfitrión.
* Relación entre masa y radio planetario.
* Asociación entre distancia y brillo aparente de las estrellas.
* Baja proporción de exoplanetas clasificados como habitables.

### ✔️ Primeras Conclusiones

Los resultados obtenidos permiten comprender mejor la composición del dataset y validar relaciones astronómicas esperadas. Además, se observó que los exoplanetas potencialmente habitables representan una pequeña fracción del total registrado, constituyendo un grupo de especial interés para futuras investigaciones.

### ✔️ Visualización de Datos

Se desarrollaron gráficos para representar visualmente la información obtenida:

* Evolución de descubrimientos por año.
* Métodos de descubrimiento de exoplanetas.
* Distribución de exoplanetas en zona habitable.
